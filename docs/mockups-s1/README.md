# Mission S1 — Étape 1 · Maquettes Lexi Shop

Fichiers HTML autonomes (polices Google, tokens alignés sur la charte). Ouvrir dans un navigateur :

- `shop-direction-a-album.html` — Direction A, album de collection
- `shop-direction-b-vitrine.html` — Direction B, vitrine de couvertures

Captures (optionnel) : depuis ce dossier, `node capture.mjs` après `npm i playwright` à la racine du dépôt, ou ouvrir les HTML et faire une capture manuelle.

Les montants en euros sont indicatifs pour la maquette uniquement ; l’implémentation passera par une fonction de formatage sur `shop_packs.price`.
